# Security Audit of OWASP Juice Shop

## Project Overview

This project presents a structured security assessment of the OWASP Juice Shop web application performed in a controlled local laboratory environment.

The assessment focused on reconnaissance, application mapping, authentication and session management, input validation, selected OWASP Top 10 categories, automated security scanning, vulnerability analysis, and remediation recommendations.

## Target

OWASP Juice Shop

Target URL:

http://localhost:3000

## Tools Used

- Kali Linux
- Docker
- Nmap
- Burp Suite Community Edition
- OWASP ZAP
- Mozilla Firefox

## Assessment Methodology

1. Lab Setup
2. Reconnaissance
3. Application Mapping
4. Authentication and Session Testing
5. Input Validation Testing
6. OWASP Top 10 Assessment
7. OWASP ZAP Automated Scanning
8. Risk Analysis
9. Remediation Recommendations

## Project Deliverables

- Security Audit Report
- Vulnerability Matrix
- Security Audit Presentation
- Practical Evidence Screenshots

## Disclaimer

This security assessment was performed only against a locally deployed OWASP Juice Shop instance in a controlled laboratory environment for educational and training purposes.
